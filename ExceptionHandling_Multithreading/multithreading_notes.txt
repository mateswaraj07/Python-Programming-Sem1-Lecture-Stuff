Multithreading:
- A thread is a light process that performs a specific task within a program
- A thread is the smallest unit of execution in a process. Multiple threads in a process share the same code and global data but maintain their own stack and registers.
- Multithreading allows you to run multiple threads concurrently within a single process, which is also known as thread-based parallelism.
- Multithreading is a technique that allows a program to execute multiple threads (smaller units of a process) concurrently.
- Program can perform multiple tasks at the same time, enhancing its efficiency and responsiveness.

Thread lifecycle:
- new -> running -> blocked -> terminated
- new : a thread is created but not yet started. it has been allocated resources but its not executing
- running : thread is started and is currently executing its code
- blocked : a thread is waiting for an event or condition to occur
- terminated : thread has completed its execution or has beedn explicitly terminated

Key functions:
- start() -> Begin the execution
- sleep() -> pause thread
- join() -> wait for thread
- Thread() -> create thread

Sleep vs Join
- sleep() pauses teh current thread. join() waits for another thread
- sleep() takes time as argument. join() takes thread object
- sleep() is used for delay. join() is used for synchronization

Lock
- A lock is a synchronization mechanism provided by the threading module that allows only one thread to access a shared resource at a time
- It prevents race conditions and ensures data consistency when multiple threads work on the same data
- create lock:
  lock = threading.lock()
- acquiring lock:
  lock.acquire()  # if the lock is free, the thread acquires it. If another thread already holds it, the thread waits.
- releasing a lock:
  lock.release()   # other waiting threads can now acquire the lock

Working of Lock:
- Thread1 -> acquire()-> critical section->release()
- Thread2 -> waits until lock is released
- Thread2 -> acquire()-> critical section->release()
