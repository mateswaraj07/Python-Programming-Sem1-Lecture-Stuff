__init__():
- It is called automatically when an object is created.
- It is ued to initialize object Attributes
- self refers to the current object
- It can take parameters
- Every object gets its own instance of variables initialized through self

Types of Data Members:
- instance data member: declared using self. each object get its own copy
- class data member: declared inside class but outside Methods. shared by all objects of the class
- private data member: begins with double underscore(__). cannot be directly accessed outside class

Getters and Setters in Python
Getter:
- A getter is a method used to access or read the value of a private data member.
- It returns the value of a private variable.
Setter:
- A setter is a method used to modify or update the value of a private data member.
- It assigns a new value to a private variable.
Syntax
Getter syntax:
def get_data(self):    
    return self.__data

Setter syntax:
def set_data(self, value):    
    self.__data = value

Property Methods
- The @property decorator allows us to access a method like a variable (without using parentheses).

Inheritance
- It is a mechanism in which one class acquires the properties and methods of another class.
- It promotes:- code reusability, reduced redundancy, easy maintenance.

Types:-
1. single inheritance:- child class inherits Attributes and methods from only one parent class
2. multiple inheritance:- child class inherits the Attributes and methods from more than  one parent
3. mutilevel inheritance:- child class inherits from a class which itself inherits from another class
4. heirarchical inheritance:- multiple child classes inherits from one class
5. hybrid inheritance:- combination of two inheritances.

Method Resolution Order (MRO) 
- is the exact sequence Python uses to search for methods and attributes across a class hierarchy. 
- It is especially important in multiple inheritance when multiple parent classes define a method with the same
- MRO decides the order in which Python searches for a method when multiple parent classes have the same method.
